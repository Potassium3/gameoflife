Game of Life

Welcome to my Game of Life simulator!

How to use

On the bottom bar there are several controls, controlling:

  • Next generation
  • Play/pause and speed
  • Zoom
  • Menus
  • Clearing board

How it works

The code splits the infinite grid into small rectangular portions containing alive cells. The program only processes these squares. You can see these portions on the "Objects" menu.
